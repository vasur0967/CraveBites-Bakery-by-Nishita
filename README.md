# CraveBites Bakery by Nishita

A modern, responsive homepage concept for CraveBites Bakery. The demo emphasizes homemade cakes, eggless options, no-maida recipes, custom celebrations, and direct WhatsApp ordering.

## Run locally

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Replace before launch

- WhatsApp number and phone number
- Exact service location and Google Maps query
- Verified customer testimonials
- Real cake photography
- Any actual ordering or backend endpoint

The current enquiry form opens WhatsApp with the submitted details, so it works without a backend.
